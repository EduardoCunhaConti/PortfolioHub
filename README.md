# 📂 PortfolioHub

Repositório central do meu portfólio em **Dados**, criado para a disciplina **Bootcamp I** (Ciência da Computação — UniCEUB). Reúne projetos acadêmicos, pessoais e de cursos complementares, organizados em pastas, documentados e versionados com Git.

- 🌐 **Site:** https://eduardocunhaconti.github.io/PortfolioHub/
- 💼 **LinkedIn:** [linkedin.com/in/eduardo-conti](https://www.linkedin.com/in/eduardo-conti)
- 👤 **GitHub:** [EduardoCunhaConti](https://github.com/EduardoCunhaConti)

## 🎯 Objetivo

Mostrar, em um só lugar, o caminho que venho percorrendo em Dados: da análise exploratória e da Engenharia de Dados até a modelagem com Machine Learning, além de um projeto de desenvolvimento em Python. Cada projeto tem sua própria pasta e seu README com objetivo, tecnologias e instruções de execução.

## ▶️ Como explorar

1. Acesse o [site](https://eduardocunhaconti.github.io/PortfolioHub/) para uma visão geral.
2. Abra a pasta do projeto desejado e leia o `README.md` dela.
3. Para rodar localmente:

```bash
git clone https://github.com/EduardoCunhaConti/PortfolioHub.git
cd PortfolioHub
```

## 🔖 Versionamento

- **Fluxo:** novas funcionalidades são desenvolvidas em branches `feat/...` e integradas à `main` por Pull Request.
- **Commits:** padrão *Conventional Commits* em português (`feat`, `docs`, `chore`, `fix`).
- **Versões:** [SemVer](https://semver.org/lang/pt-BR/), com tags anotadas `vX.Y.Z`. O histórico completo está no [CHANGELOG](CHANGELOG.md).

| Versão | Conteúdo |
|---|---|
| v1.0.0 | Site base no GitHub Pages e estrutura do repositório |
| v1.1.0 | Pastas dos projetos, índice no README e seção de projetos no site |
| v1.1.1 | Ajuste do site: remoção da seção de vídeo |
| v2.0.0 | Implantação: segurança, colaboração, integração com a API do GitHub e CI |
